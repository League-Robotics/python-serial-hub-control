# rhsp — REV Hub Serial Protocol driver

A pure-Python driver for the **REV Robotics Expansion Hub / Control Hub**,
speaking the REV Hub Serial Protocol (RHSP, also called the "DEKA" interface)
directly over a USB serial connection. It lets you discover hubs and drive
motors, servos, digital I/O, analog inputs, the on-board IMU, and I2C sensors
(color, distance) without the FTC SDK.

> Status: alpha. Derived from the community `unofficial-rev-port` projects; the
> message layer was reorganized into the `rhsp` package. See
> [docs/RHSP-Protocol.md](docs/RHSP-Protocol.md) for full provenance.

## Requirements

- Python ≥ 3.13
- A REV Expansion/Control Hub connected over USB
- [`uv`](https://docs.astral.sh/uv/) for dependency management

## Install / set up

This project is managed with **uv**. To create the environment and install the
package (editable) with its dependencies:

```bash
uv sync            # create .venv and install runtime deps
uv sync --dev      # also install dev tools (pytest)
```

Run anything inside the environment with `uv run`, e.g.:

```bash
uv run python -m rhsp           # launch the bundled interface
uv run python test/test_serial.py
```

## Quick start

```python
from rhsp import Client
from rhsp.motors import MODE_CONSTANT_VELOCITY

client = Client()
client.open()                       # auto-selects the first REV hub it finds

for module in client.discovery():   # broadcast discovery; one Module per hub
    print("Status:", module.getStatus())
    module.init_periphs()           # set up motors, servos, DIO, ADC, I2C

    module.keep_alive()             # must be repeated at least every ~2.5 s

    motor = module.motors[0]
    motor.setMode(MODE_CONSTANT_VELOCITY, 1)
    motor.enable()
    motor.setTargetVelocity(1000)
```

See [test/](test/) for runnable examples covering motors, servos, DIO, and the
color/distance sensors. **Note:** these scripts require a physical hub attached.

## Layout

```
src/rhsp/              the package
  client.py            serial framing, send/receive, checksum, discovery
  module.py            a discovered hub; owns motors/servos/DIO/ADC/I2C
  motors.py servo.py dio.py adc.py i2c.py   per-peripheral APIs
  color.py distance.py imu.py               I2C sensor drivers
  rshp_serial.py       typed pyserial wrapper + USB port enumeration
  internal/            wire-level message definitions (messages.py) and helpers
test/                  hardware example scripts
docs/                  protocol documentation (see below)
```

## Protocol documentation

The serial protocol is documented in full under [docs/](docs/):

- **[docs/RHSP-Protocol.md](docs/RHSP-Protocol.md)** — framing, transaction
  model, the complete command catalogue, encoding conventions, sequencing
  recipes, and references.
- **[docs/rhsp-protocol.json](docs/rhsp-protocol.json)** — a machine-readable
  catalogue of every command/response with field layouts and byte offsets,
  generated by **[docs/generate_protocol_json.py](docs/generate_protocol_json.py)**.
